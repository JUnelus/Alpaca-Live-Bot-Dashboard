# Alpaca Live Bot Dashboard

Public view of a fractional day-trading bot running on a live Alpaca account:
what it looked at each day, why it bought, skipped or held each symbol, and how
the account has done since launch.

**Live site:** https://junelus.github.io/Alpaca-Live-Bot-Dashboard/

Only percentages are published: no balances, dollar P&L, quantities or prices.
`data.json` is updated automatically by the bot's GitHub Actions after the
10:25 AM ET trade run and after each end-of-day run.

Not investment advice.
